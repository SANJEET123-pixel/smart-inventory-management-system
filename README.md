# Smart Inventory Management System

A Python and MySQL based inventory and sales management system.

## Features

- Add Product
- View Products
- Search Product
- Update Product
- Delete Product
- Sell Product
- View Sales

## Technologies

- Python
- MySQL
- mysql-connector-python

## Project Structure

- `main.py` - Main menu
- `database.py` - MySQL connection
- `inventory.py` - Product management
- `sales.py` - Sales management
